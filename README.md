# 楚河 · 象棋推演室

直接用浏览器打开 `index.html` 即可开始。应用使用纯前端实现，不依赖构建步骤；刷新页面会开始一局全新的会话。

## 功能

- 人机对弈：红方由你执棋，黑方由本地搜索 AI 执棋；支持点击选点和拖放。
- 自由摆棋：可为红黑双方选择棋子、放置、移动或擦除，操作写入当前棋谱。
- 棋谱侧栏：按中国象棋中文记谱显示双方着法，支持悔棋。
- 对局计时：可切换 5、10、15、30 分钟或关闭倒计时。
- AI 复盘：显示 AI 最近一步的简短理由；更完整的对弈与解释行为约定见 `MASTER_PROMPT.md`。
- 会话状态：棋盘、棋谱与时钟仅存在于当前页面内存，刷新即重置。

走子规则参考中国象棋协会审定的《象棋竞赛规则（2020版）》第一章行棋规定。AI 使用浏览器内的浅层搜索，适合练习和推演，不代表专业棋力或正式赛事裁判。
