# 楚河 · 象棋推演室

运行 `run-local.bat`（需要 Python 3）启动本地服务，浏览器会打开象棋页面。直接双击 `index.html` 仍可玩，但由于浏览器安全限制会使用内置的较弱备用 AI。

## 功能

- 人机对弈：本地服务模式使用 Pikafish WebAssembly 强引擎；红方由你执棋，黑方由引擎执棋。支持点击选点和拖放。
- 自由摆棋：可为红黑双方选择棋子、放置、移动或擦除，操作写入当前棋谱。
- 棋谱侧栏：按中国象棋中文记谱显示双方着法，支持悔棋。
- 复盘分享：点击“复制复盘码”复制整个棋局的 `XQ1` 分享码，包含自定义摆棋和 AI 简短说明；粘贴到聊天即可按格式还原。
- 对局计时：可切换 5、10、15、30 分钟或关闭倒计时。
- AI 复盘：显示 AI 最近一步的简短理由；更完整的对弈与解释行为约定见 `MASTER_PROMPT.md`。
- Pikafish 首次启动会从官方 2026-09-06 发行包提取与浏览器引擎严格匹配的棋力网络（约 54 MB 下载），并校验固定 SHA-256；需要联网。引擎运行在隔离的 Web Worker 中，搜索期间界面仍可响应。
- 会话状态：棋盘、棋谱与时钟仅存在于当前页面内存，刷新即重置。

走子规则参考中国象棋协会审定的《象棋竞赛规则（2020版）》第一章行棋规定。未启动 Pikafish 时会自动退回浏览器内的浅层搜索，该备用 AI 只适合简单推演，不代表专业棋力或正式赛事裁判。

复盘码使用 Base64URL 编码，并非加密；格式定义见 `MASTER_PROMPT.md` 的 XQ1 章节。

Pikafish 版本与第三方许可、来源和资产校验信息见 `ENGINE-NOTICES.md`。商业用途前必须另行确认 NNUE 权重许可；当前项目仅按个人非商业用途配置。
